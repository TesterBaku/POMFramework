# POMFramework

A clean reference implementation of the **Page Object Model** design pattern for Selenium test automation in Java.

## What's inside

- Page classes that encapsulate selectors and actions for each page
- Base test class with WebDriver lifecycle management
- TestNG runner
- Example tests that show how to compose page objects into readable specs

## Stack

`Java` · `Selenium WebDriver` · `TestNG` · `Maven` · `Page Object Model`

## Getting started

```bash
mvn clean test
```

## Why this repo

Page Object Model is the most common pattern in UI test automation, and most introductions to it are tangled with the rest of someone's framework. This repo keeps the pattern itself front and center — useful as a learning reference or as the starting point for a new project.
